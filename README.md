## 📖 Overview

**AlgoVerse Visualizer** is a lightweight, single-file, zero-dependency-platform web application that brings algorithms to life through beautiful, interactive, step-by-step visualizations.

Designed with education and self-learning in mind, it lets students, teachers, and developers **watch algorithms execute in real time**, understand how data structures evolve, and build intuition for computational thinking — without installing anything, without a build pipeline, and even **without an internet connection**.

The entire application ships as **one self-contained `index.html` file** — all styling, logic, and even the D3.js dependency are embedded. Just open it in a browser, and you're ready to explore.

> Built for the Arabic-speaking world first (full RTL support) but architected to be language-agnostic and easily localized.
